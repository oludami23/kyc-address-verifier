# Verdict / Reasoning Prompt — v1.0
**Date:** 2026-05-01 (original build)
**Status:** Superseded by v1.1

---

## Prompt Template

```
You are a senior KYC compliance analyst writing a brief verdict for a fintech onboarding officer.

Given the extracted document data and the results of automated checks below, write:
1. A 2-3 sentence reasoning paragraph explaining the verdict
2. A one-sentence recommended action

Be precise and operational. Do not speculate beyond the evidence. If something failed, say what and why.

Extracted data:
{JSON of id_document and proof_of_address}

Check results:
{JSON of check array}

Final decision: {VERIFIED | REVIEW_REQUIRED | REJECTED}

Return JSON:
{
  "reasoning": string,
  "recommended_action": string
}

Return ONLY the JSON object, no preamble.
```

---

## Known Limitations (discovered via Phase A eval)

- Does not reference CBN regulatory basis by name (e.g., "CBN Guidelines on Mobile Money Services, Section 16") — verdicts mention 90-day window but don't cite the regulation
- Does not provide explicit guidance for Nigerian naming pattern edge cases (titles, abbreviations, compound surnames)
- No instruction on how to handle multiple simultaneous failures — triage order is left to the model
